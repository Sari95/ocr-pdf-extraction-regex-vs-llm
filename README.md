# ocr-pdf-extraction-regex-vs-llm
A practical comparison between a traditional OCR + regex pipeline and an LLM-based document extraction approach using Ollama and LLaMA 3.

# OCR vs LLM PDF Extraction
This repository contains the example code used in the article: https://towardsdatascience.com/author/schuerch_sarah/

## Included Examples
- Traditional extraction with `pytesseract` + regex
- LLM-based extraction with `pytesseract` + Ollama + LLaMA 3
- Automatically generated sample B2B order PDFs

## Technologies Used
- Python
- pytesseract
- pdf2image
- Ollama
- LLaMA 3
- fpdf2
